# 무인화연구소 홈페이지

무인 매장 솔루션 · 무인 창업 브랜드 **무인화연구소** 홈페이지의 정적 HTML 버전입니다.
빌드 도구 없이 HTML/CSS만으로 구성되어 있어 파일을 그대로 열면 바로 확인할 수 있습니다.

## 페이지 구성

| 파일 | 내용 |
|------|------|
| `index.html` | 메인 (솔루션 / 창업 분할 히어로 + 블로그 카드) |
| `무인화연구소-회사소개.html` | 회사소개 (대표 인사말·일하는 방식·연혁) |
| `무인화연구소-블로그.html` | 블로그 카드 목록 (muinlab.io 게시글 연결) |
| `무인화연구소-솔루션.html` | 무인화 솔루션 (AIoT·출입·결제·CCTV) |
| `무인화연구소-창업.html` | 무인 창업 안내 |
| `무인화연구소-매장찾기.html` | 매장찾기 (전국 40개 지점 카드) |
| `무인화연구소-뉴스미디어.html` | 뉴스·미디어 |
| `앤딩워크라운지.html` | 앤딩워크라운지 랜딩페이지 |

기타: `robots.txt`, `sitemap.xml`, `assets/` (이미지)

## 로컬에서 보기

`index.html` 을 브라우저로 열거나, 폴더에서 간단한 정적 서버를 실행합니다.

```bash
python -m http.server 8000
```

## 배포 전 확인 사항

- `index.html` 좌측 하단 `메인 · 교체 예정` 배지 — 최종본 확정 시 제거
- 네이버 서치어드바이저 / 구글 서치콘솔 인증 코드 (`index.html` head 영역) 실제 값 입력
- `sitemap.xml` 의 `loc` 주소를 실제 배포 경로에 맞게 교체
- OG 이미지(`og-image.jpg`), 로고(`logo.png`) 파일 업로드
